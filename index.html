Step-by-step guide

Start with the easiest badges first.

🔫 Quickdraw — close within 5 minutes
  1. Open your repository and go to Issues, then click New issue.
  2. Write a title and click Submit new issue.
  3. Within 5 minutes, click Close issue.
  4. The badge can take a few hours to appear on your profile.
🦈 Pull Shark — get 2 pull requests merged
  1. Create a new branch in your repository (branch button → type a name).
  2. Make a small change to a file on that branch and commit it.
  3. Click Compare & pull request, then Create pull request.
  4. Click Merge pull request, then Confirm merge.
  5. Repeat once more. Pull requests you send to other people’s repositories and get merged count too.
😎 YOLO — merge without a review

You get this badge when you merge a pull request without anyone reviewing it. Guides online disagree: some say it works on your own repository, others say a second person is needed. Give it a try and see.

⭐ Starstruck — reach 16 stars

People star repositories they find useful or fun. Write a clear README, make something helpful, and share the link with friends and communities. Only real users should star it, so don’t fill it with fake accounts.

🧠 Galaxy Brain — 2 accepted answers
  1. Open the Discussions section (see the Q&A block below) or the GitHub Community discussions.
  2. In the Q&A category, find a question you know how to answer that has no answer yet.
  3. Write a clear, helpful reply.
  4. If the asker clicks Mark as answer, it counts. You need 2 of these.
👥 Pair Extraordinaire — co-authored commit

Co-author a commit with another person and get its pull request merged. Build a small project together with a friend.

Got a question? Ask it, or answer one!

Post your GitHub questions in Discussions. If you know the answer to someone else’s question, help them out. It’s good for them and for you.
